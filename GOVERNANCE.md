# Governance

Decisio is a small project with one maintainer.
This document says how decisions are made now and how that changes as people join.

## Roles

- **Maintainer**: reviews and merges pull requests, cuts releases, owns the evaluation records and the security process. Listed in `MAINTAINERS.md`.
- **Contributor**: anyone whose pull request has been merged.

## Decisions

- Technical decisions are made in pull requests and issues, in the open, with the measurement that supports them where one exists.
- The maintainer has the final say. Disagreements are argued on evidence; a measured result outranks an opinion, including the maintainer's.
- Changes to the served default (anything that alters a measured answer) need a record under `runs/` and an entry in `EVAL_CARD.md`.

## Becoming a maintainer

A contributor who has had several substantive pull requests merged, reviews others' work carefully, and has shown judgement about what must be measured can be invited by the existing maintainers.
Maintainers are added by consensus of the current maintainers and listed in `MAINTAINERS.md`.

## Stepping down

A maintainer who becomes inactive for six months is moved to emeritus status in `MAINTAINERS.md`, with thanks, and can return by asking.

## Changes to this document

By pull request, like everything else.
