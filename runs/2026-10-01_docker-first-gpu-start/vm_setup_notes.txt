The VM (Ubuntu 22.04) has Python 3.10 only; uv installed a managed CPython 3.12.12 (python-build-standalone 20251120, 2m06s: the CDN gave about 250 KB/s) so that uv build could run. Nothing else was installed: Docker 29.0.3, the NVIDIA runtime, nvidia-ctk 1.18.0 and uv 0.9.11 were present.

Deviation from checklist 3.0 step 6: the conformance client was run in a second container of the same image on the host network (docker run --network host), with typesafe-sdk 0.7.0 added by uv pip install --target, not from a host environment made with uv sync --extra bench. The VM reached PyPI at about 0.7 MB/s, so the CUDA wheels of torch (several GB) would have taken over an hour; the client needs no GPU. It still reaches the server from outside the server container, over the host network, exactly as a host process would.
